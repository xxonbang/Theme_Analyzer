# 트리거 감지 패턴

## 코드 변경 감지
- 파일 생성/수정 도구 사용 후
- "~파일 만들었어", "~추가했어", "~수정했어"

## 의사결정 감지 키워드
- "~하기로 했다", "~로 결정", "~쓰기로", "~방식으로 가자"
- "~보다 ~가 낫겠다", "~로 바꾸자"

## Todo 감지 키워드
- "나중에 ~", "다음에 ~", "~해야 해", "~추가해야"
- "TODO:", "~는 나중에"

## 아키텍처 변경 감지
- "구조를 ~로", "폴더를 ~로", "~패턴 쓰자"
- "분리하자", "모듈화", "리팩토링"

## API 변경 감지
- "엔드포인트 추가", "라우트 ~", "API ~"
- "endpoint", "route", "controller"

## 세션 마무리 감지
- "오늘은 여기까지", "다음에 이어서", "일단 멈추자"
- "수고했어", "고마워", "내일 계속"
