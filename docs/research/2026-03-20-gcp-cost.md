# GCP 월간 예상 비용 조사 - KIS Strategy Builder/Backtester

> 조사일: 2026-03-20 KST
> 기준 리전: asia-northeast3 (서울)

## 워크로드 요약

| 서비스 | 구성 | 포트 |
|--------|------|------|
| Strategy Builder | FastAPI + Next.js | 8000, 3000 |
| Backtester | FastAPI + Next.js + Docker (QuantConnect Lean) | 8002, 3001 |

- **운영 시간**: 평일 09:00~15:30 KST (6.5시간/일, ~22일/월 = **143시간/월**)
- **24시간 운영**: 24 x 30 = **720시간/월**
- Python 3.11+, Node.js 18+, Docker 필수

## 1. Compute Engine (VM)

### 스펙별 가격 (asia-northeast3 서울 리전, On-Demand)

| 머신 타입 | vCPU | RAM | 시간당 | 월 24시간 | 월 장시간만 (143h) | Spot 시간당 |
|-----------|------|-----|--------|-----------|-------------------|-------------|
| e2-medium | 1 (공유) | 4GB | $0.043 | $31.38 | $6.15 | $0.0128 |
| e2-standard-2 | 2 | 8GB | $0.086 | $62.75 | $12.30 | $0.0256 |
| e2-standard-4 | 4 | 16GB | $0.172 | $125.51 | $24.60 | $0.0511 |

**디스크 비용** (별도): Standard PD ~$0.048/GB/월, SSD PD ~$0.204/GB/월 (서울 리전)
- 50GB SSD 기준: 약 $10.20/월 (VM 중지해도 과금)

### 최소 스펙 권장

| 구성 | 권장 머신 | 이유 |
|------|-----------|------|
| Strategy Builder만 | e2-standard-2 (2vCPU/8GB) | FastAPI + Next.js 구동에 충분 |
| Builder + Backtester 통합 | e2-standard-4 (4vCPU/16GB) | Docker(Lean 엔진) 운영 시 메모리 필요 |

### 예상 월 비용

| 시나리오 | 머신 | VM 비용 | 디스크(50GB SSD) | 합계 |
|----------|------|---------|-----------------|------|
| e2-standard-2, 장시간만 | 2vCPU/8GB | $12.30 | $10.20 | **~$22.50** |
| e2-standard-4, 장시간만 | 4vCPU/16GB | $24.60 | $10.20 | **~$34.80** |
| e2-standard-2, 24시간 | 2vCPU/8GB | $62.75 | $10.20 | **~$72.95** |
| e2-standard-4, 24시간 | 4vCPU/16GB | $125.51 | $10.20 | **~$135.71** |

### VM 자동 시작/종료

GCP **Instance Schedule** 기능으로 평일 08:50 시작, 15:40 종료 자동화 가능 (무료).

### 장단점

**장점:**
- Docker 자유롭게 사용 가능 (Lean 엔진 호환성 최고)
- 설정 단순, SSH 직접 접근
- Instance Schedule로 비용 절감 자동화
- 장시간만 운영 시 매우 저렴

**단점:**
- 서버 관리 필요 (OS 업데이트, 보안 등)
- 스케일링이 수동
- 종료된 VM에서도 디스크 비용 발생

## 2. Cloud Run (컨테이너 서버리스)

### 가격 체계 (Tier 2 - 아시아 리전)

| 항목 | Request-based | Instance-based (Always-on) |
|------|---------------|---------------------------|
| CPU | $0.0000336/vCPU-초 | $0.0000252/vCPU-초 |
| Memory | $0.0000035/GiB-초 | $0.0000028/GiB-초 |
| Requests | $0.40/백만건 | $0.40/백만건 |

### 예상 월 비용 계산

**가정**: 4개 서비스(FastAPI x2 + Next.js x2), 각 1vCPU/1GB, 장시간(143시간) 운영

Instance-based 기준:
- CPU: 4 vCPU x 143h x 3600초 x $0.0000252 = **$51.94**
- Memory: 4 GiB x 143h x 3600초 x $0.0000028 = **$5.77**
- 합계: **~$57.71/월** (장시간만)

**2vCPU/2GB로 축소 시** (FastAPI 2개를 1 컨테이너로):
- 3 서비스, 각 1vCPU/1GB = CPU $38.96 + MEM $4.33 = **~$43.29/월**

24시간 운영 시:
- CPU: 4 x 720h x 3600 x $0.0000252 = **$261.27**
- Memory: 4 x 720h x 3600 x $0.0000028 = **$29.03**
- 합계: **~$290.30/월**

### Docker (Lean 엔진) 문제

> **Cloud Run은 Docker-in-Docker를 지원하지 않습니다.**

QuantConnect Lean 엔진을 Docker로 실행해야 하는 Backtester는 Cloud Run에서 직접 실행 불가. Lean을 네이티브 컨테이너로 빌드하거나, Backtester만 Compute Engine에서 운영해야 합니다.

### 장단점

**장점:**
- 요청 없으면 자동 스케일 다운 (0까지)
- 인프라 관리 불필요
- 빠른 배포 (컨테이너 push만)

**단점:**
- Docker-in-Docker 불가 (Lean 엔진 직접 실행 불가)
- 장시간 연속 운영 시 Compute Engine보다 비쌈
- Cold start 지연 (수 초)
- WebSocket 지원 제한

## 3. GKE Autopilot (Kubernetes)

### 가격 (us-central1 기준, 서울 리전은 ~20% 높음)

| 항목 | 가격 |
|------|------|
| vCPU | $0.0445/시간 (~서울: $0.053) |
| Memory | $0.0049/GiB-시간 (~서울: $0.006) |
| 클러스터 관리비 | $0.10/시간 (고정) |

### 예상 월 비용 계산

**가정**: 4 Pod (4vCPU, 4GiB 총합), 서울 리전 추정

장시간만 (143시간):
- 클러스터 관리비: $0.10 x 720h = **$72.00** (클러스터는 항상 과금!)
- vCPU: 4 x 143h x $0.053 = **$30.32**
- Memory: 4 x 143h x $0.006 = **$3.43**
- 합계: **~$105.75/월**

24시간 운영:
- 클러스터: $72.00
- vCPU: 4 x 720h x $0.053 = **$152.64**
- Memory: 4 x 720h x $0.006 = **$17.28**
- 합계: **~$241.92/월**

> **주의**: 클러스터 관리비 $72/월은 워크로드 유무와 관계없이 고정 발생!

### 장단점

**장점:**
- Docker 네이티브 지원 (Lean 엔진 Pod으로 실행)
- 자동 스케일링, 자동 복구
- 프로덕션 급 안정성

**단점:**
- 클러스터 관리비 $72/월 고정 (소규모에 부담)
- Kubernetes 학습 곡선
- 설정 복잡성 (YAML, Helm 등)
- 소규모 워크로드에 과도한 솔루션

## 결론 및 권장

### 1순위: Compute Engine e2-standard-4 (장시간만 운영)

- **월 ~$35** (가장 저렴)
- Docker/Lean 엔진 완벽 지원
- Instance Schedule로 자동 시작/종료
- Builder + Backtester 통합 운영 가능

### 2순위: 하이브리드 (Cloud Run + Compute Engine)

- Strategy Builder: Cloud Run (~$29/월)
- Backtester: Compute Engine e2-standard-2 (~$23/월)
- 합계 ~$52/월, 관리 부담 분산

### 비추천: GKE Autopilot

- 클러스터 관리비만 $72/월 → 소규모 프로젝트에 과도
- 2~4개 서비스 운영에 Kubernetes는 과잉
